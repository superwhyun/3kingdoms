# 천하삼분 (가칭)

삼국시대 배경의 **비동기 턴제 온라인 전략 게임**. 플레이어는 군웅 중 한 세력을 맡아 매달(1턴) 내정·인사·외교·출진 명령을 제출한다. 모든 플레이어가 턴을 종료하거나 마감 시간이 지나면 서버가 모든 세력의 명령을 동시에 해결한다. 플레이어가 없는 세력과 마감까지 명령을 내지 않은 세력은 AI가 운영한다.

인물·지명은 역사 기록을 따르며, 능력치·규칙·UI는 이 프로젝트의 독자 설계다.

## 구조

| 경로 | 내용 |
|---|---|
| `packages/data` | 시나리오 데이터와 zod 스키마 (190년, 도시 39 / 세력 11 / 장수 약 110) |
| `packages/engine` | 순수 TS 규칙 엔진. `resolveTurn(state, orders, {ai})`는 결정론적 (시드 RNG) |
| `apps/server` | Fastify + WebSocket + `node:sqlite`. 인증, 로비, 명령 검증, 턴 해결, 마감 스케줄러, 채팅 |
| `apps/web` | React + Vite. 로비, SVG 지도, 명령 입력, 외교, 기록, 채팅 |

## 실행

Node 22.13 이상, pnpm 10.

```bash
pnpm install
pnpm test          # 엔진·서버 테스트
pnpm dev           # 서버 :3000 + Vite :5173 (http://localhost:5173)
```

배포형 실행 (빌드된 웹을 서버가 함께 서빙):

```bash
pnpm build && pnpm start   # http://localhost:3000
```

환경 변수: `PORT`, `DB_PATH`(기본 `apps/server/data.db`), `TICK_MS`(마감 확인 주기, 기본 15000).

## 규칙 요약

- **턴**: 1턴 = 1개월. 명령 처리 순서는 외교 → 내정·인사 → 이동·수송 → 출진.
- **내정**: 개발(농업·상업·성벽·민심), 징병, 훈련, 군량 거래, 탐색, 등용, 포상. 장수 1명은 한 달에 한 번만 행동한다.
- **경제**: 매달 상업 수입과 병사 급료(금)·군량 소비가 발생한다. 7월에 수확한다.
- **전투**: 인접 도시로 출진하며 최대 12라운드까지 자동으로 계산한다. 병력·훈련도·지휘관 무력/지력·성벽이 반영된다. 군량이 떨어지면 퇴각한다.
- **함락**: 수비 장수는 탈출하거나 포로가 된다. 군주가 잡히면 후계자가 옹립되고, 도시를 모두 잃으면 세력이 멸망한다.
- **외교**: 동맹·정전(12개월) 제안/수락, 협정 파기, 공물로 우호도를 올린다.
- **시야**: 타 세력 도시의 금·군량은 보이지 않고, 인접 도시의 병력만 근사치로 보인다.
- **승리**: 다른 세력을 모두 멸망시키면 통일 승리. 종료 연도가 되면 도시 수 1위가 승리한다.
