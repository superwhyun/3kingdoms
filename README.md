# 천하삼분 (가칭)

삼국시대 배경의 **비동기 턴제 온라인 전략 게임**. 플레이어는 군웅 중 한 세력을 맡아 매달(1턴) 내정·인사·외교·출진 명령을 제출한다. 모든 플레이어가 턴을 종료하거나 마감 시간이 지나면 서버가 모든 세력의 명령을 동시에 해결한다. 플레이어가 없는 세력과 마감까지 명령을 내지 않은 세력은 AI가 운영한다.

인물·지명은 역사 기록을 따르며, 능력치·규칙·UI는 이 프로젝트의 독자 설계다.

## 구조

| 경로 | 내용 |
|---|---|
| `packages/data` | 시나리오 데이터와 zod 스키마 (190년, 도시 39 / 세력 11 / 장수 약 110) |
| `packages/engine` | 순수 TS 규칙 엔진. `resolveTurn(state, orders, {ai})`는 결정론적 (시드 RNG) |
| `apps/server` | Fastify + WebSocket + `node:sqlite`. 인증, 로비, 명령 검증, 턴 해결, 마감 스케줄러, 채팅 |
| `apps/web` | React + Vite. 로비, SVG 지도, 명령 입력, 외교, 기록, 채팅 |

## 실행

Node 22.13 이상, pnpm 10.

```bash
pnpm install
pnpm test          # 엔진·서버 테스트
pnpm dev           # 서버 :3000 + Vite :5173 (http://localhost:5173)
```

배포형 실행 (빌드된 웹을 서버가 함께 서빙):

```bash
pnpm build && pnpm start   # http://localhost:3000
```

환경 변수: `PORT`, `DB_PATH`(기본 `apps/server/data.db`), `TICK_MS`(마감 확인 주기, 기본 15000).

## 관리자(admin)

- 최초 가입자가 admin이 되며, admin은 다른 사용자에게 권한을 주거나 뺄 수 있다(마지막 admin은 해제 불가).
- 모든 조정값(전투 계수·상성·비용·경제·세율·시설·계략·이벤트·외교·AI)은 `packages/engine/src/rules.ts`의 `DEFAULT_RULES`에 모여 있다.
- **기본 규칙**: 새로 만드는 게임에 복사된다. 기본값과 다른 항목만 서버 DB에 저장된다.
- **게임별 규칙**: 진행 중인 게임의 규칙을 수정하면 다음 턴 해결부터 적용된다. 턴 강제 해결도 여기서 한다.

## 규칙 요약

- **턴**: 1턴 = 1개월. 명령 처리 순서는 외교 → 내정·인사 → 이동·수송 → 출진.
- **내정**: 개발(농업·상업·성벽·민심), 징병, 훈련, 군량 거래, 탐색, 등용, 포상. 장수 1명은 한 달에 한 번만 행동한다.
- **경제**: 매달 상업 수입과 병사 급료(금)·군량 소비가 발생한다. 7월에 수확한다.
- **병종**: 창병·기병·궁병·수군·공성. 도시는 병종별로 병력을 보유하며 징병 비용이 다르다. 수군은 강을 끼고 있는 도시에서만 징병할 수 있다.
  - 상성: 창 > 기 > 궁 > 창. 수군은 강 도로에서 강하고 육로에서 약하다. 공성은 교전에 약하지만 성벽을 크게 깎는다.
  - 장수 병종 적성은 능력치에서 파생되고, 일부 장수는 보정을 받는다(예: 강동 장수는 수군).
- **전투 (10라운드 사전 전략)**: 공격측은 출진할 때, 수비측은 도시별 '수비 전략'으로, 라운드마다 지휘 장수·병종·투입 병력을 미리 정한다. 서로의 계획은 모른다.
  - 라운드 순서대로 양측 배치가 맞붙는다. 손실 = K × √(내 투입 × 상대 투입) × √(상대 질 / 내 질). 질 = 훈련 × 적성 × 상성 × 지형 × 성벽(수비).
  - 많이 투입하면 주는 피해와 받는 피해가 함께 커진다. 큰 병력에 소규모로 찔러보면 거의 전멸한다.
  - 수비 투입 병력이 그 라운드에 전멸하면, 전멸에 쓰이고 남은 공격 병력이 선형으로 밀고 들어간다(남은 피해 = 남은 병력 × K × √(질 비율)). 남은 피해는 성벽 내구도로 넘어간다(1명당 1, 공성은 5배). 성벽이 0이면 수비 예비대가 받는다. 공격 투입 병력이 전멸하고 남은 피해는 소멸한다.
  - 수비가 대기(투입 0)하면 공격군이 예비대와 성벽을 직접 타격한다. 공격이 대기하면 군량만 소모한다.
  - 살아남은 병력은 예비대로 돌아가 다음 라운드에 다시 쓴다. 수비 병력이 전멸하면 함락, 10라운드 뒤에도 남아 있으면 공격측이 철수한다.
  - 전투 리포트에는 라운드별 결과와 상대 전략이 공개된다(당사자만 볼 수 있다). 수비 전략은 바꿀 때까지 유지되므로, 정찰 공격으로 상대 전략을 알아낸 뒤 다음 달에 본공격을 할 수 있다.
- **세율·태수**: 도시별 세율(낮음/보통/높음)이 수입과 월 민심을 바꾼다. 태수는 매달 농업·상업 중 낮은 쪽을 자동으로 개발하고, 매력이 높으면 민심을 올리며, 반란 확률을 낮춘다. 둘 다 장수 행동을 쓰지 않는다.
- **시설**: 시장(수입), 농장(수확), 병영(징병 비용 할인), 연병장(훈련 상승량). 최대 3단계이고 건설에 여러 달이 걸린다. 도시마다 한 번에 하나만 지을 수 있다.
- **계략**: 인접 적 세력 도시에 유언비어(민심↓), 선동(훈련↓·병력 이탈), 이간(장수 충성↓), 방화(군량·금↓)를 건다. 성공률은 실행 장수와 대상 도시 최고 지력의 차이로 정해지고, 실패하면 발각되어 우호도가 떨어질 수 있다.
- **이벤트**: 풍작·흉년(수확 월), 역병, 홍수(강 도시 6~8월), 반란(민심이 낮을 때). 반란군이 수비병을 이기면 도시가 중립이 된다.
- **함락**: 수비 장수는 탈출하거나 포로가 된다. 군주가 잡히면 후계자가 옹립되고, 도시를 모두 잃으면 세력이 멸망한다.
- **외교**: 동맹·정전(12개월) 제안/수락, 협정 파기, 공물로 우호도를 올린다.
- **시야**: 타 세력 도시의 금·군량은 보이지 않고, 인접 도시의 병력만 근사치로 보인다.
- **승리**: 다른 세력을 모두 멸망시키면 통일 승리. 종료 연도가 되면 도시 수 1위가 승리한다.
